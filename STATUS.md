## Работает

`docker compose up --build` поднимает db, redis, mailpit, backend, worker и frontend. Worker подключается к `redis://redis:6379/0`. Redis и PostgreSQL снаружи не публикуются. На хосте открыты frontend (`5173`), API (`8000`) и веб-интерфейс Mailpit (`8025`).

Расчёт счёта — чистая функция `price_visit`, без записи счёта и без заезда. 15 тестов pytest:

`docker compose run --rm backend pytest`

На чистой тестовой базе прошли 14 тестов Django:

`docker compose run --rm -v ./backend:/app -e PYTHONDONTWRITEBYTECODE=1 backend python manage.py test apps.accounts.tests.test_auth apps.bookings.tests.test_db_constraints`

`A@x.com` и `a@x.COM` — одна почта, повтор падает с `IntegrityError`. Регистрация и вход по почте возвращают токен DRF. База отвергает пересечение броней в статусах `active` и `checked_in`, длительность вне 15 минут–24 часа, второй активный визит того же номера или места, второй счёт на визит, повтор номера у другого водителя и второе напоминание на бронь. Начальный тариф Asia/Bishkek засеян миграцией.
