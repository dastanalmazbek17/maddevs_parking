# Статус

Обновлено: 2026-10-17 14:50:13 UTC.

## Работает

`docker compose up --build` поднимает db, redis, mailpit, backend, worker и frontend. Worker подключается к `redis://redis:6379/0`. Redis и PostgreSQL снаружи не публикуются. На хосте открыты frontend (`5173`), API (`8000`) и веб-интерфейс Mailpit (`8025`).

На чистой тестовой базе прошли 12 тестов ограничений:

`docker compose run --rm -v ./backend:/app -e PYTHONDONTWRITEBYTECODE=1 backend python manage.py test apps.bookings.tests.test_db_constraints`

База отвергает пересечение броней в статусах `active` и `checked_in`, длительность вне 15 минут–24 часа, второй активный визит того же номера или места, второй счёт на визит, повтор номера у другого водителя и второе напоминание на бронь. Начальный тариф Asia/Bishkek засеян миграцией.
