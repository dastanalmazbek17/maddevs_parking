## Работает

`docker compose up --build` поднимает db, redis, mailpit, backend, worker и frontend. После миграций entrypoint вызывает `seed_demo`: тариф (Азия/Бишкек, день 07:00–23:00 по 200 копеек, ночь по 100), места `P01`–`P12`, пользователь `demo@example.com` с паролем из `DEMO_PASSWORD` (в `.env.example` — `ParkDemo-2026`) и машина `A000AA`. Повторный запуск команды ничего не дублирует.

HTTP API описан в `docs/API.md`. Регистрация и вход по токену, свои машины, публичное табло мест, брони, заезд и выезд шлагбаума, история визитов и счетов. Ошибки домена приходят как `{"code", "detail"}`. 69 тестов pytest:

`docker compose run --rm backend pytest`
