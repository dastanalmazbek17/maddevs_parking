# Статус

Обновлено: 2026-10-17 14:13:59 UTC.

## Работает

`docker compose up --build` поднимает db, redis, mailpit, backend, worker и frontend. Worker подключается к `redis://redis:6379/0`. Redis и PostgreSQL снаружи не публикуются. На хосте открыты frontend (`5173`), API (`8000`) и веб-интерфейс Mailpit (`8025`).

В базе Compose применены миграции моделей. Два теста ограничений проходят:

`docker compose run --rm -v ./backend:/app -e PYTHONDONTWRITEBYTECODE=1 backend python manage.py test apps.bookings.tests.test_db_constraints`

Пересекающаяся активная бронь, пустой интервал брони, второй активный визит того же номера или того же места и второй счёт на один визит отвергаются PostgreSQL. Номер сохраняется в нормализованном виде.
