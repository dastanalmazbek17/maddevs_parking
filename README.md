# Парковка с тарификацией

Учебный сервис платной парковки: водитель бронирует место, заезжает через симулятор шлагбаума и получает счёт по минутам. Задание лежит в `docs/TASK.md`.

Сейчас в репозитории каркас каталогов под выбранный стек. Работоспособность, пробелы и открытые вопросы — в `STATUS.md`. Почему проект разложен так — в `DECISIONS.md`.

## Стек

- Backend: Django, Django REST Framework, Channels, Celery
- Данные и канал: PostgreSQL, Redis
- Frontend: React, Vite
- Почта на локальной машине: Mailpit, по умолчанию письма печатаются в консоль

## Каталоги

- `backend/` — API, модели, вебсокеты занятости мест, фоновые задачи
- `frontend/` — интерфейс
- `docs/` — текст задания

`docker compose up --build` поднимает каркас. Redis и PostgreSQL доступны только внутри сети Compose. Продуктовых сценариев ещё нет.
