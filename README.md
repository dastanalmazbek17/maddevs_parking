# Парковка с тарификацией

Сервис платной парковки: водитель бронирует место, заезжает через симулятор шлагбаума и платит по минутам. Репозиторий: https://github.com/dastanalmazbek17/maddevs_parking

Задание — `docs/TASK.md`. Состояние — `STATUS.md`. Журнал решений — `DECISIONS.md`. Следующий заход — `NEXT.md`.

## Чем делали

Проект писался в Cursor, в режиме агента, модель Grok 4.7. Стек оставлен тот, что уже выбран в `docs/TASK.md`: Django, PostgreSQL, Redis, Celery и React. Автор ими пользуется, отдельный язык и набор инструментов ради задания не брались.

Чужой шаблон приложения в репозитории не лежит. Журнал не фиксирует `django-admin startproject` и `create-vite`. Миграции помечены как собранные Django 6.1.2.

## Требования

Нужны Docker и Docker Compose v2: команда `docker compose`, не `docker-compose`. Проверено на Docker Compose v5.5.1. Других программ на хосте нет.

Порты 8000, 5173, 8025 и 8080 должны быть свободны. PostgreSQL и Redis наружу не публикуются.

## Запуск

Из корня репозитория:

```bash
cp .env.example .env
docker compose up --build
```

Команда остаётся в этом терминале. Контейнеры читают `.env.example`: в `docker-compose.yml` у backend, worker и beat стоит `env_file: .env.example`. Файл `.env` в git не входит. Правка только `.env` на пароль и почту не влияет, пока Compose указывает на `.env.example`.

Приложение: http://localhost:8080. Письма: http://localhost:8025.

Демо-водитель после `seed_demo`: почта `demo@example.com`, пароль `ParkDemo-2026` (переменная `DEMO_PASSWORD` в `.env.example`), машина `A000AA`, места `P01`–`P12`. Повторный запуск сиды ничего не дублирует.

## Тесты

```bash
docker compose run --rm backend pytest
docker compose run --rm --no-deps frontend npm test
```

## Две вкладки

1. Откройте http://localhost:8080 в двух вкладках.
2. В обеих нажмите «Схема». Дождитесь надписи «Связь: онлайн» и двенадцати мест. На чистой базе все «свободно».
3. Первую вкладку не переключайте: уход со «Схемы» закрывает её сокет.
4. Во второй откройте «Шлагбаум», введите номер, которого ещё нет на парковке, и нажмите «Заезд».
5. В первой, без перезагрузки, это место станет «занято».
6. Во второй нажмите «Выезд». В первой место снова станет «свободно». Строка с итогом появляется во второй вкладке, на шлагбауме, а не на схеме.
